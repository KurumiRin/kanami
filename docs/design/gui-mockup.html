Key records stay in memory only, at most the latest 5000 are kept, closing the viewer clears them, and nothing is written to disk. The system does not hand input in password fields to kanami. "All keys" shows regular typing, so take care when recording or sharing the screen.

Config source

Edit config.toml directly. It is checked live while you type, and takes effect only after saving with ⌘SCtrl+S. With errors it is not applied, and remapping keeps using the last correct configuration.
